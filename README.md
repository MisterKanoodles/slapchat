# Slapchat

A mobile-first social camera web app inspired by the camera-first Snapchat experience from 2018. This repository currently contains a front-end prototype with sample Stories, friends, streaks, and chat UI.

## Run locally

Open `index.html` in a modern browser. No build step or dependencies are required.

## Team workflow

Create a GitHub repository and invite your collaborator. Each person can clone the repository, make a feature branch, and open a pull request to merge their work into the shared default branch.

## Current prototype

- Responsive camera-first layout with desktop side panels and mobile bottom navigation
- Sample Stories, friend activity, chat sheet, snap shutter, and camera flip interaction
- No sign-in, real camera access, persistence, messaging, or server yet
